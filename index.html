About Highlights Research Software

I'm a PhD candidate at Stony Brook University.

I work with research teams at Brookhaven National Laboratory and Stony Brook Institute of Advanced Computational Science. I have conducted my research on various high-performance computing architectures, including NERSC GPU clusters, the ALCF dataflow AI testbed, and FPGA embedded accelerators.

I am a full stack Post Training Infrastructure researcher. My current research focuses on distributed systems for AI agents, particularly long-context memory. My projects connect KV-cache scheduling, scalable RL rollouts, and GPU–dataflow inference to support long-horizon agent workloads, building on my work in GPU–dataflow heterogeneous LLM execution, spatial dataflow compilers, and FPGA pipelines.

Highlights

2026 Fall

  • Disaggregated Decoding on Heterogeneous GPU–Dataflow AI Accelerators

    Distributed System · LLM inference

    • Heterogeneous LLM inference that separates GPU prefill from dataflow-accelerator decoding for long-horizon agents.
    • Run prefill on 8 NVIDIA H200 SXM GPUs and CSL decoding on Cerebras WSE-3, developing the request-handoff and state-transfer path.
    • 2,080 output tokens/s (1.30×), with p95 inter-token latency of 12 ms versus 16 ms in the GPU-only scenario.

2026 Summer

  • Long-Context KV Cache Management for Large-Scale Computer-Use Agents

    Distributed System · LLM inference

    • KV-cache scheduling for multiple long-horizon computer-use agents sharing GPU memory.
    • Develop cache allocation and residency scheduling; tested with 50 concurrent long-horizon agents on 8 NVIDIA H200 GPUs.
    • 30% lower allocated KV memory (320 → 224 GiB) and 33% lower p95 resumption latency (450 → 300 ms) for 50 agents.

2026 Spring

  • Distributed RL Rollout Acceleration on a 256-GPU Compute Cluster

    Distributed System · Post Training

    • Distributed RL rollout infrastructure targeting load balance, lower GPU idle time, and stable execution.
    • Built a Go scheduling layer using vLLM and speculative decoding; tested on 256 NVIDIA A100 80GB GPUs at NERSC.
    • 51,200 output tokens/s (1.25×) and GPU-worker idle time of 18% versus 28% at 256 GPUs.

2025 Spring

  • Spatial Mapping and Explicit Routing of LLM Kernels on Dataflow Accelerators Using Low-Level Programming

    GitHub

    AI accelerators · LLM inference

    • LLM execution on programmable wafer-scale hardware, with explicit control over computation, communication, and persistent model state.
    • Implemented CSL kernels, Python host orchestration, and tensor placement on Cerebras CS-3 at Argonne National Lab AI Testbed.
    • The complete 64-layer Qwen3.8 network generated two continuous sentences plus EOS (37 tokens) on one physical WSE-3. Strict CPU numerical parity remains open.

2024 Fall

  • Dataflow Graph Compilation for General-Purpose MIMD Accelerators

    GitHub

    AI accelerators · Compilers

    • A compiler and programming model for treating spatial dataflow architectures as general-purpose MIMD numerical accelerators.
    • Built a Python compiler with a C++ tensor frontend and CSL code generation for PE placement, communication routing, and buffer-lifetime management.
    • The published Cerebras SDK-simulator snapshot records 141 qualified configurations, including a 25-node resident attention graph, with numerical and communication-protocol validation.

Agent Post Training

  1. Milestone-Aware On-Policy Distillation for Long-Horizon Reasoning

    Changyuan Lin, Xueru Bai, Haoliang Zhang, Lingzhi Yang, Tianxiang Xu, Yiqi Wang, Xander Zhang

    AAAI 2027

    Uses solution milestones to locate where a model's reasoning stalls, then concentrates teacher feedback on those steps to make long-horizon reasoning training more efficient.

  2. CoRD: On-Policy Distillation via Correction Reconstruction

    Shaoke Fang, MEIJIA CHEN, Lingzhi Yang, Saisai Hu, Jiayi, Chao Wang, Xander Zhang, Wenfei Wu

    ICLR 2027

    Selects and reweights complementary token-level corrections so a smaller supervision budget can approximate the combined learning signal of full-response teacher feedback.

  3. Learning Not to Forget How to Improve: Meta-Forgetting in Self-Evolving Agents

    Jianfeng Chen, MEIJIA CHEN, Yi Ge, Shuwen Zhou, Fengjiao Sheng, Yuxuan Fang, Shuhan Sun, Ruixin Li, Lingzhi Yang, Xander Zhang

    ICLR 2027

    Studies how agents can lose the ability to improve themselves, and uses Improvement Function Replay to preserve effective improvement strategies while adapting to new tasks.

  4. Shapley-Guided Rollout Selection for Reinforcement Learning with Verifiable Rewards

    Zhiming Lin, Kai Zhao, Lingzhi Yang, Saisai Hu, Qirui Tu, JiaLi, CHEN RONGRU, Xander Zhang

    ICLR 2027

    Uses Shapley values to select a small, complementary set of rollouts, preserving the full group's learning direction while reducing the number of responses used in policy updates.

  5. View-Decomposed On-Policy Distillation for Robust Reasoning in Large Language Models

    MEIJIA CHEN, Shangqing Shi, Lingzhi Yang, Zijun Tian, Bojun Li, Yufan Zou, Xander Zhang

    ICLR 2027

    Compares teacher predictions across different wordings of the same task, retaining shared guidance and useful uncertainty to make student reasoning less sensitive to prompt wording.

Long Horizon Agent

  • BioWorkflow-Gym

    GitHub (work in progress) Manuscript

    Scientific agents · Workflow environments

    • A training and evaluation environment for long-horizon scientific agents constructing and executing verifiable bioinformatics workflows.
    • Built a Python/BioBlend system on NERSC using peer-reviewed Galaxy IWC workflows; ran 50 concurrent secure rollouts lasting 1.5–2 hours each.
    • Weight-free skill evolution improved the composite score from 33/100 to 51/100 (+54.5%), measuring workflow graph completion, execution completion, and result correctness.

  • BioWorkflow-Bench

    GitHub

    Scientific agents · Evaluation

    • A benchmark for evaluating agents on complex, branching bioinformatics workflows with verifiable outputs.
    • Built Python dataset tooling and Docker/Conda reference pipelines using real public data and ground-truth outputs.
    • Released 71 additional tasks across six domains, covering workflows up to depth 8 with 16+ CLI tools.

FPGA Accelerators

  • Fused Kernel on FPGA Using HLS

    AI accelerators · Compilers

    • Fused FPGA computation exposed as a custom instruction callable from software.
    • Added dedicated buffers around fixed systolic-array IP using HLS, exposing a fused custom instruction through an ARM C++ compiler; tested on Xilinx U280.
    • 1.5× device throughput (9 → 6 ms per invocation) and 30% less off-chip traffic (40 → 28 MiB).

  • Accelerated Radon Transformation on FPGA Using HLS

    AI accelerators · Numerical Kernels

    • A stream-processing unit for hardware-accelerated Radon-transform computation.
    • Built and tested a stream-processing unit on Xilinx Zynq-7010, using HLS and HDL to connect spatially arranged PEs into a pipeline.
    • 6× transform throughput (180 → 30 ms/frame) and relative L2 error ≤ 0.001 for the proposed 256 × 256, 180-angle workload.
